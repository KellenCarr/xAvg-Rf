Connect an agent

SkillHub speaks a small, stable JSON contract. Point any agent harness at this server, present a bearer token, and your agent can discover, install, and submit skills under its assigned scopes.

  1. Discover the server
    Every SkillHub server publishes a discovery doc with its endpoints, supported auth schemes, and scopes.
    $ curl {{ base_url }}/.well-known/skillhub.json
  2. Get a connector token
    Ask an admin to register your agent at /connectors. They pick a name and scopes (read install submit), and the server returns a token once.
    SKILLHUB_TOKEN=skh_xxxxxxxxxxxxxxxxxxxxxxxxxxxx
  3. Confirm the connection
    The agent calls /api/connectors/me with its token. The server validates the token, records last_seen_at, and returns the connector's identity and scopes.
    $ curl -H "Authorization: Bearer $SKILLHUB_TOKEN" {{ base_url }}/api/connectors/me
  4. Crawl the library
    List entries, fetch manifests, and pull payloads. All /api/* endpoints accept the same bearer token; scope is enforced per endpoint.
    $ curl -H "Authorization: Bearer $SKILLHUB_TOKEN" \
    "{{ base_url }}/api/entries?kind=skill&status=approved"

$ curl -H "Authorization: Bearer $SKILLHUB_TOKEN" \
    {{ base_url }}/api/entries/acme/code-reviewer

$ curl -H "Authorization: Bearer $SKILLHUB_TOKEN" -o code-reviewer.tar.gz \
    {{ base_url }}/api/entries/acme/code-reviewer/payload
  5. (Optional) submit findings back
    Agents with the submit scope can publish new manifests. The submission lands as status=pending and waits for admin approval.
    $ curl -H "Authorization: Bearer $SKILLHUB_TOKEN" \
    -F manifest_yaml=@manifest.yaml \
    {{ base_url }}/api/entries

Discovery document

This is the contract your agent should rely on. URLs and the manifest shape are stable within skillhub/v0.

GET /.well-known/skillhub.json

{
  "service": "skillhub",
  "version": "0.1.0",
  "spec": "skillhub/v0",
  "base_url": "{{ base_url }}",
  "auth": { "schemes": ["bearer"], "bearer": {"header": "Authorization", "prefix": "Bearer "} },
  "scopes": ["read", "install", "submit"],
  "endpoints": { ... },
  "kinds": ["skill", "mcp_server"]
}
